Tier 0 PeerSession demo

Inviter tab: ① Create room. SENN Core builds an offer through RTCPeerConnection and the URL-fragment signaling adapter buffers it. Click ② export URL to copy the resulting #i=…&s=… URL. Joiner tab: open that URL — the page auto-joins, accepts the offer, builds an answer, and buffers it. Click ② export URL again, paste back into the inviter's ③ import field. ICE candidates round-trip through additional export/import cycles until the data channel reaches connected. Then either side can send free text via ④ send.
