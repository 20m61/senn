# SENN Naming and Brand

## Name

SENN

## Meaning

SENN is derived from the Japanese word "sen" meaning line.
It represents the lightweight line formed directly between peers.

## Tagline

線でつながる。サーバに預けない。

## English Tagline

Direct lines. No server custody.

## Brand Keywords

- Line
- Peer
- Direct
- Lightweight
- Static add-ons
- Local-first
- Trust
- Flow
- Presence
- Open ecosystem

## Do

- Use SENN as the project name.
- Use SENN Core for the runtime.
- Use SENN Add-ons for extensions.
- Use SENN Registry for add-on discovery.
- Use SENN Verified for reviewed add-ons.

## Do Not

- Use SENN Software as the official name.
- Imply all communication always succeeds without relay.
- Claim perfect anonymity.
- Claim all third-party add-ons are completely safe.
