# SENN Project Charter

## Mission

SENN は、ブラウザだけでユーザー同士を直接つなぎ、テキスト、音声、ファイル、状態、操作イベント、アドオンデータなどをサーバに保存せず流通させる、オープンなP2Pコミュニケーション基盤である。

SENN は、サードパーティ開発者が静的アドオンとして新しい体験を追加できる仕組みを提供し、XR、アバター、共同編集、ゲーム、イベント、教育、展示、ローカル保存など、多様なコミュニケーション体験をコミュニティが自由に発明できる場を作る。

## Vision

サーバに預けるコミュニケーションから、ユーザー同士のあいだに直接生まれるコミュニケーションへ。

SENN は、巨大な中央サーバに体験を預けるのではなく、ブラウザ同士の「線」によって、その場限りの体験や、必要に応じて残せる交換物を流通させる。

## Core Message

アドオンは体験を作る。
コアは安全な流通を担う。
データはユーザー間で直接動く。

## Principles

1. Core is open source.
2. Dynamic data flows peer-to-peer by default.
3. Servers do not store conversations, files, profiles, or room state.
4. Add-ons are static files.
5. Add-ons do not own dynamic network connections.
6. Add-ons communicate only through SENN Core APIs.
7. Core provides sandboxing, permissions, validation, and local storage boundaries.
8. Users choose what to store, share, and delete.
9. Third-party developers can create and distribute add-ons.
10. Business should grow around trust, distribution, verification, support, and deployment — not by closing the core.

## Non-goals

SENN is not:

- A centralized chat service.
- A server-side message storage system.
- A large-scale video meeting platform.
- A general-purpose social network.
- A closed app platform.
- A plugin system where extensions can freely exfiltrate user data.
- A promise of perfect anonymity.
