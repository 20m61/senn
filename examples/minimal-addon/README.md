# Minimal Add-on

The smallest valid SENN add-on. Use it as:

- A starting template for new add-ons.
- A fixture for `scripts/validate-addon-manifest.ts`.
- A runtime smoke test for the sandbox iframe loader.

## Files

```
manifest.json   # SENN add-on manifest
index.html      # Entry document loaded in the sandboxed iframe
addon.js        # Bridge stub
style.css       # Cosmetic only
```
