# Invite round-trip fixture

This directory is the canonical conformance fixture for
[`/docs/room-and-invite-spec.md`](../../docs/room-and-invite-spec.md).

| File | Role |
|------|------|
| [`payload.json`](payload.json) | Canonical decoded `InvitePayload`. |
| [`encoded.txt`](encoded.txt) | Canonical encoded form. Generated by `scripts/validate-invite.ts --update` and committed. |
| [`url.txt`](url.txt) | Full invite URL built against `https://senn.example/r/`. Generated alongside `encoded.txt`. |

## Run

```sh
pnpm tsx scripts/validate-invite.ts examples/invite-roundtrip/payload.json
```

The validator:

1. Encodes `payload.json` and asserts byte-equality against `encoded.txt`.
2. Decodes `encoded.txt` and asserts deep equality with `payload.json`.
3. Builds a URL and asserts its length ≤ 2048 characters.

To regenerate after a deliberate spec change, add `--update`.

## Negative fixture

The same script can run against any file; sample bad payloads to exercise
the validator:

```sh
echo '{"v":2}' > /tmp/bad.json
pnpm tsx scripts/validate-invite.ts /tmp/bad.json || echo "rejected as expected"
```
