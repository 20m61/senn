# Signaling bundle round-trip fixture

Canonical conformance fixture for
[`/docs/signaling-url-fragment-spec.md`](../../docs/signaling-url-fragment-spec.md).

| File | Role |
|------|------|
| [`bundle.json`](bundle.json) | Canonical decoded `SignalingBundleV1`. |
| [`encoded.txt`](encoded.txt) | Canonical encoded form. Generated by `pnpm validate:bundle --update` and committed. |

## Run

```sh
pnpm validate:bundle examples/signaling-url-fragment-roundtrip/bundle.json
```

The validator:

1. Encodes `bundle.json` and compares to `encoded.txt`.
2. Decodes `encoded.txt` and asserts deep equality with `bundle.json`.

To regenerate after a deliberate spec change, add `--update`.
